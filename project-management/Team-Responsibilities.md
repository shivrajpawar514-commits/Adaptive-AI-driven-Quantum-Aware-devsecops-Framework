# Project Team Roles & Responsibilities

This document defines the roles, module ownerships, and key deliverables assigned to each member of our research team.

---

## 1. Devam (Research Lead)
- **Role**: Backend Architecture & Integration Engineer
- **Responsibilities**:
  - Sets up API servers, MongoDB configuration schemas, and cluster routing middleware.
  - Provisions infrastructure as code using **Terraform** and writes system automation tasks using **Ansible**.
  - Configures **Docker** packaging files and **Kubernetes** dynamic NetworkPolicies.
  - Acts as Git repository master, managing pull requests, code styling, and overall integration.
- **Key Modules**: Backend core, database drivers, automation engines, infrastructure scripts.

---

## 2. Kalpesh (Security Lead)
- **Role**: Access Control & Policy Security Engineer
- **Responsibilities**:
  - Implements admin user validation endpoints using Elliptic Curve Cryptography (**ECC**).
  - Handles **JWT** signature validation, token refresh parameters, and redis blacklist revocation.
  - Formulates Zero-Trust security rules and maps Open Policy Agent (**OPA**) decision gate configurations.
  - Conducts risk validation checks and authorization reviews.
- **Key Modules**: Authentication service, API gateway routes, OPA decision logs.

---

## 3. Dil (AI Lead)
- **Role**: Machine Learning Research Engineer
- **Responsibilities**:
  - Develops feature engineering pipelines, normalization rules, and local PCA dimensionality reductions.
  - Implements unsupervised **Autoencoder** and **Isolation Forest** threat detection models.
  - Preprocesses network and resource flow datasets (e.g. CSE-CIC-IDS2018).
  - Evaluates models using standard performance parameters (Accuracy, F1-Score, FPR).
- **Key Modules**: AI engine, telemetry collector preprocess, risk score generator.

---

## 4. Shivraj (Quantum Lead)
- **Role**: Quantum Simulation & Cryptographic Migration Engineer
- **Responsibilities**:
  - Develops **Qiskit** script models showing Bloch Sphere simulator mappings.
  - Evaluates NIST Post-Quantum Cryptography (**PQC**) standard libraries (ML-KEM, ML-DSA) inside container testbeds.
  - Measures resource footprints (CPU/memory) and connection latencies of PQC handshakes.
  - Drafts the Quantum-Aware Security Planning and migration reports.
- **Key Modules**: Quantum planning module, Qiskit script libraries.

---

## 5. ChatGPT (Research Advisor)
- **Role**: Technical Architect & Academic Advisor
- **Responsibilities**:
  - Advises on system design choices, API specifications, and database architectures.
  - Reviews implementation plans and identifies research gaps in contemporary literature.
  - Suggests experimental benchmarks and supports the team in formatting academic papers.
- **Key Modules**: Architecture review, research proposals editing.
